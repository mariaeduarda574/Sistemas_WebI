Sobre PHP

O PHP é uma linguagem usada para criar sites dinâmicos. Ele funciona no servidor, processando dados antes de mostrar ao usuário. Permite conexão com banco de dados e criação de sistemas como login e formulários.

É fácil de aprender e muito usado no desenvolvimento web. Também se integra com HTML e ajuda a deixar os sites mais interativos e funcionais.

Esse código em PHP usa um switch para verificar o valor da variável $dia

  • $dia = "terça"; → define o dia como terça
  • switch($dia) → compara o valor com os casos

  • case "sexta" → mostraria “Fim de semana chegando!”
  • default → executa se não for nenhum dos casos.

Como funciona este código?

Esse código em PHP verifica a idade de uma pessoa e mostra uma mensagem na tela.

  • $idade = 18; → define a idade como 18.
  • if($idade >= 18) → verifica se a idade é maior ou igual a 18.
  • echo "Maior de idade"; → mostra essa mensagem se for maior de idade.
  • else → caso não seja, executa outra opção.
  • echo "Menor de idade"; → mostra que é menor de idade
